# Guía de Utilidad y Ejecución para la Lección 6 (Scripts)

Este documento detalla cómo compilar y ejecutar los archivos de la Lección 6 tanto en consola local como mediante comandos directos

## ⚙️ Comandos de Compilación y Ejecución en Terminal

Si descargas el archivo `Leccion6Completed.java` en tu computadora y tienes instalado el Java Development Kit (JDK), puedes ejecutarlo con los siguientes comandos:

### En Windows (PowerShell / Símbolo del Sistema):

```bash
# Paso 1: Compilar el archivo Java a bytecode (.class)
javac Leccion6Completed.java

# Paso 2: Ejecutar el programa compilado
java Leccion6Completed
En Linux / macOS (Bash / Zsh):
Bash
# Compilar y ejecutar en una sola linea
javac Leccion6Completed.java && java Leccion6Completed

```

🌐 Ejecución Directa en Editores en Línea (Online)
Si no cuentas con el JDK instalado en tu máquina:
Abre OnlineGDB Java Compiler.
Selecciona el lenguaje Java en la esquina superior derecha.
Pega el código de Leccion6Completed.java.
Haz clic en el botón verde Run (o presiona la tecla F9).
La terminal integrada en la parte inferior mostrará los resultados de la ejecución.
