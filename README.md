# Fundamentos de Java para Principiantes

## Resumen del Curso
Este curso de 1 hora introduce a estudiantes de secundaria a los fundamentos de la programación con Java, incluyendo programación orientada a objetos. **¡No requiere descargas!** Solo abre tu navegador web.

- **Duración total**: ~60 minutos
- **Público Objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
- **Prerrequisitos**: Ninguno
- **Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)
- **📂 Repositorio de Código Fuente**: [https://github.com/JouleTracker/java-fundamentals-course-VoltLab](https://github.com/JouleTracker/java-fundamentals-course-VoltLab)

## Secuencia de la Lección

### Lección 1: ¿Qué es Java y la Programación? (5 minutos)
- **Descripción**: Aprende qué es la programación, cómo funcionan las instrucciones de una computadora y por qué Java es un excelente lenguaje para comenzar. Conoce sus principales características y desarrolla tu primer programa "Hola, mundo".
- **Enlace**: [Ver la lección en YouTube](https://youtu.be/e-CJTcVVT5Y)
- **Duración**: 3 minutos de teoría y 2 minutos de práctica.
- **Conclusiones clave**: Java es un lenguaje orientado a objetos y multiplataforma, utilizado para desarrollar aplicaciones, sistemas empresariales y videojuegos.
- **Ejemplo práctico**: Crear y ejecutar un programa utilizando `System.out.println("Hola, mundo!");`.
- **Empieza a programar**: [Abrir OnlineGDB](https://onlinegdb.com/hOQLbUZNL)

### Lección 2: Variables y tipos de datos (8 minutos)
- **Descripción**: Aprende a almacenar datos en Java usando variables.
- **Enlace**: [Ver la lección](https://youtu.be/KlLTknfOZlc)
- **Conclusiones clave**: Usa int, String; declara como `int age = 15;`
- **Práctica**: [Clic para programar](https://www.jdoodle.com/online-java-compiler) 👈 **¡No es necesario registrarse!**

### Lección 3: Estructuras de control: Decisiones y bucles (12 minutos)
- **Descripción**: Aprende a controlar el flujo de ejecución evaluando condiciones con if-else if-else y automatizando repeticiones con bucles for y while.
- **Enlace**: [Ver la lección](https://youtu.be/ePMdDLMUc-w)
- **Conclusiones clave**: Toma de decisiones con `if (estatura >= 140) {}`; repetición contada con `for (int i = 5; i >= 1; i--) {}`; ciclo condicional con `while (bateria < 100) {}`.
- **Práctica**: [Clic para programar](https://www.jdoodle.com/ga/kj9b-u4m5-9pdt) 👈 **¡Inicio inmediato!**

### Lección 4: Métodos, Entrada/Salida e Introducción a la POO (12 minutos)
- **Descripción**: Crea funciones reutilizables con parámetros y retorno, interactúa con el usuario mediante Scanner e introduce el modelado de clases y objetos.
- **Enlace**: [Ver la lección](https://youtu.be/75rHadiNZ7M)
- **Conclusiones clave**: Métodos modulares con parámetros y valor de retorno; captura de datos en consola con `Scanner`; diseño de clases con atributos, constructores y creación de objetos con `new Mascota()`.
- **Práctica**: [Haz clic para practicar](https://www.jdoodle.com/ga/d6bj-y7n8-zje2) 👈 **¡No necesitas registrarte!**

### Lección 5: Fundamentos de POO y programas sencillos (15 minutos)
- **Descripción**: Construye clases con atributos privados, constructores, getters/setters y desarrolla un sistema de gestión para una tienda de mascotas en Java.
- **Enlace**: [Ver la lección](https://youtu.be/6Sf7poDfdQ8)
- **Conclusiones clave**: Encapsulación con `private`, getters y setters; separación de responsabilidades entre `Mascota`, `Cliente`, `TiendaMascotas` y `Main`; uso de arreglos de objetos.
- **Proyecto final**: [Crea tu aplicación POO](https://onlinegdb.com/ibj_fSgxB) 👈 **¡Practica en OnlineGDB!**

### Lección 6: Consejos y próximos pasos (10 minutos)
- **Descripción**: Mejores prácticas de código limpio, lectura de errores comunes de consola, técnicas básicas de depuración y recursos para seguir aprendiendo.
- **Enlace**: [Ver la lección](https://youtu.be/gHEnulUZS9Q)
- **Consejos clave**: Nombres en `camelCase` y sangría ordenada; lectura de errores (`; expected`, mayúsculas/minúsculas, llaves); depuración con `System.out.println`; documentación de Oracle Java, W3Schools y Exercism.
